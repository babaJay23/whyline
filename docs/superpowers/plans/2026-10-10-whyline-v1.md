# whyline v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zero-install npm CLI that reads Claude Code and Codex session transcripts from disk and annotates a git diff with, per hunk, the prompt that caused it, the agent's reasoning, which agent wrote it, what the turn cost, and six deterministic review flags.

**Architecture:** Four pure stages behind one CLI. Adapters turn each harness's transcript into one normalized `Event[]`. The ledger replays edit events into a per-file line table that remembers which edit last wrote each line. The resolver parses `git diff --unified=0`, looks each changed line up in the ledger, assembles provenance, and applies flag rules. Renderers (terminal, HTML, JSON) consume the same `AnnotatedDiff` object.

**Tech Stack:** TypeScript 5, Node 20+, ESM. Zero runtime dependencies (arg parsing via `node:util` `parseArgs`, colors via a 20-line ANSI helper, diff parsing and patch parsing written here). Dev: `typescript`, `vitest`, `@types/node`. Published as `whyline` with a `bin`.

**Spec:** `docs/superpowers/specs/2026-10-10-whyline-design.md`

## Global Constraints

- Node `>=20`. ESM only (`"type": "module"`). Target `ES2022`, module `NodeNext`.
- Zero runtime dependencies. `package.json` `dependencies` must stay `{}`. CI fails if `src/` imports `http`, `https`, `net`, `undici`, or calls `fetch`.
- No model calls, no network, no daemon, no config file, no hooks in v1.
- Never fabricate attribution: an unmatched line is `provenance: null` and the hunk is flagged `untraced`.
- Flags are deterministic functions of the transcript and the diff. No heuristics that depend on time of day, locale, or environment.
- Transcript lines that fail to parse are skipped and counted, never fatal.
- Output file writes only to paths the user named (`--html`, `--json` to stdout).
- Exit codes: `0` success, `1` usage error, `2` not a git repo or empty diff, `3` no sessions found.
- Code style: small files, one job each. Comments only where the why is not obvious. No emoji in code, output, or docs. Commit messages terse and imperative.
- Simplification from the spec, agreed here: the `patch` `EditOp` is dropped. The Codex adapter normalizes each `*** Update File` chunk into a `replace` op and `*** Add File` into `write`, so the ledger handles only `replace | write | delete`.
- Simplification from the spec: on a failed `replace` match the ledger records the failure and keeps replaying later edits (they still require exact matches, so they cannot misattribute). `driftedAt` is the first failure time. This is stricter about honesty and more useful than stopping.
- Test fixtures are hand-built JSONL that copy the observed record shapes field-for-field (see spec section 4); they are small and contain no personal content.

## Review Focus

Inputs the spec implies but that a naive implementation breaks on. Each has a test pinned to the owning task below.

1. **Edits made before the base commit.** A session can start before `HEAD`; replaying those edits against the `HEAD` version of the file fails to match. The ledger must only replay edits whose timestamp falls inside the review window. (Task 8, `selectEdits` test.)
2. **Untracked new files.** `git diff HEAD` does not list files the agent created but never `git add`ed, and those are the most common agent output. The CLI must synthesize all-added diffs for untracked files. (Task 2, `untracked` test; Task 13 e2e.)
3. **CRLF and trailing-newline differences.** Harness `old_string` matching is byte-exact; a file saved with CRLF or without a final newline must not silently produce drift for every edit. The ledger splits on `\n` and preserves `\r` inside line text so matches stay exact; the resolver compares line text after stripping a trailing `\r`. (Task 4 and Task 10 tests.)
4. **Same old_string appearing twice.** `replace_all: false` must change only the first occurrence, exactly as the harness did; `replace_all: true` changes all. (Task 4 test.)
5. **Transcript rows with the right type but wrong shape.** For example an `assistant` row whose `message.content` is a string, a `tool_use` with no `input`, a Codex `function_call` whose `arguments` is not valid JSON. Adapters must skip and count, never throw. (Task 6 and Task 7 malformed-row tests.)

```ts
import { execFileSync } from 'node:child_process';
import { mkdtempSync, mkdirSync, realpathSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { dirname, join } from 'node:path';

export function makeRepo(files: Record<string, string> = {}) {
  // realpath so the directory matches what `git rev-parse --show-toplevel` reports (macOS /var -> /private/var).
  const dir = realpathSync(mkdtempSync(join(tmpdir(), 'whyline-repo-')));
  const git = (...args: string[]) =>
    execFileSync('git', args, {
      cwd: dir,
      encoding: 'utf8',
      env: {
        ...process.env,
        GIT_AUTHOR_NAME: 't', GIT_AUTHOR_EMAIL: 't@t', GIT_COMMITTER_NAME: 't', GIT_COMMITTER_EMAIL: 't@t',
      },
    }).trim();
  git('init', '-q', '-b', 'main');
  const write = (path: string, content: string) => {
    mkdirSync(dirname(join(dir, path)), { recursive: true });
    writeFileSync(join(dir, path), content);
  };
  for (const [p, c] of Object.entries(files)) write(p, c);
  const commit = (msg: string) => {
    git('add', '-A');
    git('commit', '-q', '--allow-empty', '-m', msg);
    return git('rev-parse', 'HEAD');
  };
  return { dir, write, commit, git };
}
```

```ts
import { execFileSync } from 'node:child_process';
import { readFileSync } from 'node:fs';
import { join } from 'node:path';

function git(root: string, args: string[]): string | null {
  try {
    return execFileSync('git', args, { cwd: root, encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'], maxBuffer: 64 * 1024 * 1024 });
  } catch {
    return null;
  }
}

export function repoRoot(cwd: string): string | null {
  const out = git(cwd, ['rev-parse', '--show-toplevel']);
  return out ? out.trim() : null;
}

export function commitTime(root: string, rev: string): number {
  const out = git(root, ['show', '-s', '--format=%ct', rev]);
  if (!out) throw new Error(`cannot read commit time for ${rev}`);
  return Number(out.trim()) * 1000;
}

export function show(root: string, rev: string, path: string): string | null {
  return git(root, ['show', `${rev}:${path}`]);
}

export function diffText(root: string, range: string | null): string {
  const args = ['diff', '--unified=0', '--no-color', '--no-ext-diff', '--find-renames'];
  args.push(range ?? 'HEAD');
  return git(root, args) ?? '';
}

export function untracked(root: string): string[] {
  const out = git(root, ['ls-files', '--others', '--exclude-standard']);
  return out ? out.split('\n').filter(Boolean) : [];
}

export function readWorkingFile(root: string, path: string): string | null {
  try {
    return readFileSync(join(root, path), 'utf8');
  } catch {
    return null;
  }
}

export function parseRange(range: string | null): { base: string; head: string | null } {
  if (!range) return { base: 'HEAD', head: null };
  const i = range.indexOf('..');
  if (i === -1) return { base: range, head: null };
  return { base: range.slice(0, i), head: range.slice(i + 2) || 'HEAD' };
}
```

```ts
import type { FileDiff, FileStatus, Hunk } from '../types.js';

const HUNK = /^@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@/;

export function parseUnifiedDiff(text: string): FileDiff[] {
  const files: FileDiff[] = [];
  let cur: FileDiff | null = null;
  let hunk: Hunk | null = null;
  let binary = false;

  for (const raw of text.split('\n')) {
    if (raw.startsWith('diff --git ')) {
      if (cur && !binary) files.push(cur);
      cur = { path: '', oldPath: null, status: 'modified', hunks: [] };
      hunk = null;
      binary = false;
      continue;
    }
    if (!cur) continue;
    if (raw.startsWith('Binary files ')) { binary = true; continue; }
    if (raw.startsWith('new file mode')) { cur.status = 'added'; continue; }
    if (raw.startsWith('deleted file mode')) { cur.status = 'deleted'; continue; }
    if (raw.startsWith('rename from ')) { cur.oldPath = raw.slice('rename from '.length); cur.status = 'renamed'; continue; }
    if (raw.startsWith('rename to ')) { cur.path = raw.slice('rename to '.length); continue; }
    if (raw.startsWith('--- ')) {
      const p = raw.slice(4);
      if (p !== '/dev/null' && !cur.path && cur.status !== 'renamed') cur.path = p.replace(/^a\//, '');
      continue;
    }
    if (raw.startsWith('+++ ')) {
      const p = raw.slice(4);
      if (p !== '/dev/null') cur.path = p.replace(/^b\//, '');
      continue;
    }
    const m = HUNK.exec(raw);
    if (m) {
      hunk = {
        oldStart: Number(m[1]), oldLines: m[2] === undefined ? 1 : Number(m[2]),
        newStart: Number(m[3]), newLines: m[4] === undefined ? 1 : Number(m[4]),
        removed: [], added: [],
      };
      cur.hunks.push(hunk);
      continue;
    }
    if (!hunk) continue;
    if (raw.startsWith('+')) hunk.added.push(raw.slice(1));
    else if (raw.startsWith('-')) hunk.removed.push(raw.slice(1));
    // "\ No newline at end of file" and anything else: ignore
  }
  if (cur && !binary) files.push(cur);
  return files;
}

export function syntheticAdded(path: string, content: string): FileDiff {
  const lines = splitLines(content);
  const status: FileStatus = 'added';
  if (lines.length === 0) return { path, oldPath: null, status, hunks: [] };
  return {
    path, oldPath: null, status,
    hunks: [{ oldStart: 0, oldLines: 0, newStart: 1, newLines: lines.length, removed: [], added: lines }],
  };
}

/** Split on \n only, drop the empty tail after a final newline, keep \r inside lines. */
export function splitLines(content: string): string[] {
  if (content === '') return [];
  const parts = content.split('\n');
  if (parts[parts.length - 1] === '') parts.pop();
  return parts;
}
```

- [ ] **Step 3: Implement src/ledger/ledger.ts**

The table is kept as lines, but `replace` works on the joined text so matching is byte-exact like the harness. After each replacement we rebuild lines and re-derive attribution: lines before the match keep their ids, lines produced by the replacement get the edit id, lines after the match keep their ids shifted.

```ts
import type { EditEvent, LedgerLine, LineTable } from '../types.js';
import { splitLines } from '../resolve/diff.js';

export function replay(base: string | null, edits: EditEvent[]): LineTable {
  let lines: LedgerLine[] = splitLines(base ?? '').map((text) => ({ text, editId: null }));
  let driftedAt: number | null = null;
  const failed: string[] = [];

  for (const e of [...edits].sort((a, b) => a.at - b.at)) {
    switch (e.op.type) {
      case 'write':
        lines = splitLines(e.op.content).map((text) => ({ text, editId: e.id }));
        break;
      case 'delete':
        lines = [];
        break;
      case 'replace': {
        const next = applyReplace(lines, e.op.old, e.op.new, e.op.all, e.id);
        if (next === null) {
          failed.push(e.id);
          if (driftedAt === null) driftedAt = e.at;
        } else {
          lines = next;
        }
      }
    }
  }
  return { lines, driftedAt, failed };
}

export function tableText(t: LineTable): string {
  return t.lines.length === 0 ? '' : t.lines.map((l) => l.text).join('\n') + '\n';
}

function applyReplace(lines: LedgerLine[], old: string, neu: string, all: boolean, editId: string): LedgerLine[] | null {
  if (old === '') return null;
  // The harness matched against the real file, which usually ends in a newline
  // that the line table does not store. Try with it first, then without.
  const joined = lines.map((l) => l.text).join('\n');
  let curText = joined + '\n';
  let from = curText.indexOf(old);
  if (from === -1) { curText = joined; from = curText.indexOf(old); }
  if (from === -1) return null;

  let cur = lines;
  while (from !== -1) {
    const to = from + old.length;
    const startLine = lineIndexAt(curText, from);
    const endLine = lineIndexAt(curText, Math.max(from, to - 1));
    const newText = curText.slice(0, from) + neu + curText.slice(to);
    const newLines = splitLines(newText);
    // Lines before startLine and after endLine are untouched; everything between
    // (inclusive) was produced by this replacement.
    const tailCount = cur.length - endLine - 1;
    const headCount = startLine;
    const produced = newLines.length - headCount - tailCount;
    const out: LedgerLine[] = [];
    for (let i = 0; i < headCount; i++) out.push(cur[i]!);
    for (let i = 0; i < produced; i++) out.push({ text: newLines[headCount + i]!, editId });
    for (let i = 0; i < tailCount; i++) out.push(cur[endLine + 1 + i]!);
    cur = out;
    curText = newText;
    if (!all) break;
    from = curText.indexOf(old, from + neu.length);
  }
  return cur;
}

function lineIndexAt(text: string, offset: number): number {
  let n = 0;
  for (let i = 0; i < offset; i++) if (text.charCodeAt(i) === 10) n++;
  return n;
}
```

```ts
import type { EditOp } from '../types.js';

export function parseApplyPatch(input: string): { file: string; op: EditOp }[] {
  if (!input.includes('*** Begin Patch')) return [];
  const out: { file: string; op: EditOp }[] = [];
  const lines = input.split('\n');

  let file: string | null = null;
  let mode: 'add' | 'update' | null = null;
  let added: string[] = [];
  let chunk: { old: string[]; neu: string[] } | null = null;

  const flushChunk = () => {
    if (file && chunk && (chunk.old.length || chunk.neu.length)) {
      out.push({ file, op: { type: 'replace', old: chunk.old.join('\n'), new: chunk.neu.join('\n'), all: false } });
    }
    chunk = null;
  };
  const flushFile = () => {
    if (file && mode === 'add') out.push({ file, op: { type: 'write', content: added.length ? added.join('\n') + '\n' : '' } });
    if (mode === 'update') flushChunk();
    file = null; mode = null; added = []; chunk = null;
  };

  for (const line of lines) {
    if (line.startsWith('*** Add File: ')) { flushFile(); file = line.slice(14).trim(); mode = 'add'; continue; }
    if (line.startsWith('*** Update File: ')) { flushFile(); file = line.slice(17).trim(); mode = 'update'; continue; }
    if (line.startsWith('*** Delete File: ')) { flushFile(); out.push({ file: line.slice(17).trim(), op: { type: 'delete' } }); continue; }
    if (line.startsWith('*** Move to: ') && file && mode === 'update') {
      out.push({ file, op: { type: 'delete' } });
      file = line.slice(13).trim();
      continue;
    }
    if (line.startsWith('*** End Patch')) { flushFile(); break; }
    if (line.startsWith('*** ')) continue; // Begin Patch and anything unknown

    if (mode === 'add') {
      if (line.startsWith('+')) added.push(line.slice(1));
      continue;
    }
    if (mode === 'update') {
      if (line.startsWith('@@')) { flushChunk(); chunk = { old: [], neu: [] }; continue; }
      if (!chunk) chunk = { old: [], neu: [] };
      if (line.startsWith('-')) chunk.old.push(line.slice(1));
      else if (line.startsWith('+')) chunk.neu.push(line.slice(1));
      else if (line.startsWith(' ')) { chunk.old.push(line.slice(1)); chunk.neu.push(line.slice(1)); }
      else if (line === '') { /* blank context line inside chunk */ chunk.old.push(''); chunk.neu.push(''); }
    }
  }
  flushFile();
  return out;
}
```

Note on the blank-line branch: Codex emits an empty line (no leading space) for blank context lines in some versions. Treating it as context on both sides is the only interpretation that still matches the file.

```ts
import { readFileSync } from 'node:fs';

export function readJsonl(path: string): { rows: unknown[]; skipped: number } {
  const rows: unknown[] = [];
  let skipped = 0;
  for (const line of readFileSync(path, 'utf8').split('\n')) {
    if (line.trim() === '') continue;
    try {
      rows.push(JSON.parse(line));
    } catch {
      skipped++;
    }
  }
  return { rows, skipped };
}

export function firstLine(path: string): unknown | null {
  const text = readFileSync(path, 'utf8');
  const nl = text.indexOf('\n');
  try {
    return JSON.parse(nl === -1 ? text : text.slice(0, nl));
  } catch {
    return null;
  }
}

/** Narrow unknown to a string-keyed object without asserting its shape. */
export function obj(v: unknown): Record<string, unknown> | null {
  return v !== null && typeof v === 'object' && !Array.isArray(v) ? (v as Record<string, unknown>) : null;
}
export const str = (v: unknown): string | null => (typeof v === 'string' ? v : null);
export const num = (v: unknown): number => (typeof v === 'number' && Number.isFinite(v) ? v : 0);
```

```ts
import { existsSync, readdirSync, realpathSync } from 'node:fs';
import { basename, join } from 'node:path';
import type { Adapter, EditOp, Event, SessionRef } from '../types.js';
import { readJsonl, obj, str, num } from './jsonl.js';

export function slug(absPath: string): string {
  return absPath.replace(/[\\/]/g, '-');
}

function real(p: string): string {
  try { return realpathSync(p); } catch { return p; }
}

function inside(root: string, cwd: string): boolean {
  const r = real(root), c = real(cwd);
  return c === r || c.startsWith(r.endsWith('/') ? r : r + '/');
}

export const claudeCode: Adapter = {
  harness: 'claude-code',

  async discover(repoRoot, home) {
    const projects = join(home, '.claude', 'projects');
    if (!existsSync(projects)) return [];
    const prefix = slug(real(repoRoot));
    const refs: SessionRef[] = [];
    for (const dir of readdirSync(projects)) {
      if (!dir.startsWith(prefix)) continue; // sessions run in subdirectories share the prefix
      const dirPath = join(projects, dir);
      for (const f of readdirSync(dirPath)) {
        if (!f.endsWith('.jsonl')) continue;
        const path = join(dirPath, f);
        const { rows } = readJsonl(path);
        const meta = sessionMeta(rows);
        if (!meta || !inside(repoRoot, meta.cwd)) continue;
        refs.push({ harness: 'claude-code', id: meta.id ?? basename(f, '.jsonl'), path, cwd: meta.cwd, startedAt: meta.start, endedAt: meta.end });
      }
    }
    return refs.sort((a, b) => a.startedAt - b.startedAt);
  },

  async read(ref) {
    const main = readJsonl(ref.path);
    const events = parseRows(main.rows, ref.id, null);
    let skipped = main.skipped;
    const subDir = join(ref.path.replace(/\.jsonl$/, ''), 'subagents');
    if (existsSync(subDir)) {
      for (const f of readdirSync(subDir)) {
        const m = /^agent-(.+)\.jsonl$/.exec(f);
        if (!m) continue;
        const sub = readJsonl(join(subDir, f));
        skipped += sub.skipped;
        events.push(...parseRows(sub.rows, ref.id, m[1]!));
      }
    }
    events.sort((a, b) => a.at - b.at);
    return { events, skipped };
  },
};

function sessionMeta(rows: unknown[]): { id: string | null; cwd: string; start: number; end: number } | null {
  let cwd: string | null = null, id: string | null = null, start = Infinity, end = -Infinity;
  for (const r of rows) {
    const o = obj(r); if (!o) continue;
    cwd ??= str(o.cwd); id ??= str(o.sessionId);
    const t = ts(o); if (t !== null) { start = Math.min(start, t); end = Math.max(end, t); }
  }
  if (!cwd || start === Infinity) return null;
  return { id, cwd, start, end };
}

function ts(o: Record<string, unknown>): number | null {
  const s = str(o.timestamp);
  const t = s ? Date.parse(s) : NaN;
  return Number.isNaN(t) ? null : t;
}

/** agentId === null means the main transcript; otherwise rows belong to that subagent. */
function parseRows(rows: unknown[], sessionId: string, agentId: string | null): Event[] {
  const events: Event[] = [];
  const agent = agentId ?? sessionId;
  let turnId = 'turn-0';
  const seenRequests = new Set<string>();
  const pendingSpawns = new Map<string, { name: string; brief: string }>();

  for (const r of rows) {
    const o = obj(r); if (!o) continue;
    const at = ts(o); if (at === null) continue;
    const msg = obj(o.message);
    const type = str(o.type);

    if (type === 'user') {
      if (agentId !== null) { turnId = str(o.promptId) ?? turnId; }
      const result = obj(o.toolUseResult);
      if (result) {
        const childAgentId = str(result.agentId);
        const callId = toolResultId(msg);
        const spawn = callId ? pendingSpawns.get(callId) : undefined;
        if (childAgentId && spawn) {
          events.push({ kind: 'spawn', id: `${callId}:spawn`, sessionId, agentId: agent, turnId, at, childAgentId, ...spawn });
          pendingSpawns.delete(callId!);
        }
        continue;
      }
      if (o.isMeta === true || agentId !== null) continue;
      const text = humanText(msg);
      if (text === null) continue;
      turnId = str(o.promptId) ?? str(o.uuid) ?? turnId;
      if (text.includes('[Request interrupted by user')) {
        events.push({ kind: 'interrupt', id: `${turnId}:interrupt`, sessionId, agentId: agent, turnId, at });
      } else {
        events.push({ kind: 'prompt', id: str(o.uuid) ?? `${turnId}:prompt`, sessionId, agentId: agent, turnId, at, text });
      }
      continue;
    }

    if (type !== 'assistant' || !msg) continue;
    if (agentId !== null) turnId = str(o.promptId) ?? turnId;
    const rid = str(o.requestId);
    const usage = obj(msg.usage);
    if (usage && rid && !seenRequests.has(rid)) {
      seenRequests.add(rid);
      events.push({
        kind: 'usage', id: `${rid}:usage`, sessionId, agentId: agent, turnId, at,
        input: num(usage.input_tokens), output: num(usage.output_tokens),
        cacheRead: num(usage.cache_read_input_tokens), cacheWrite: num(usage.cache_creation_input_tokens),
      });
    }
    const content = Array.isArray(msg.content) ? msg.content : [];
    for (const block of content) {
      const b = obj(block); if (!b) continue;
      const bt = str(b.type);
      if (bt === 'text' && str(b.text)) {
        events.push({ kind: 'reasoning', id: `${str(o.uuid)}:text`, sessionId, agentId: agent, turnId, at, text: b.text as string, visible: true });
      } else if (bt === 'thinking' && str(b.thinking)) {
        events.push({ kind: 'reasoning', id: `${str(o.uuid)}:thinking`, sessionId, agentId: agent, turnId, at, text: b.thinking as string, visible: false });
      } else if (bt === 'tool_use') {
        const id = str(b.id) ?? `${str(o.uuid)}:tool`;
        const name = str(b.name) ?? '';
        const input = obj(b.input);
        if (!input) continue;
        for (const op of editOps(name, input)) {
          events.push({ kind: 'edit', id, sessionId, agentId: agent, turnId, at, tool: name, file: op.file, op: op.op });
        }
        if (name === 'Bash' && str(input.command)) {
          const command = input.command as string;
          events.push({ kind: 'shell', id, sessionId, agentId: agent, turnId, at, command, touches: pathTokens(command) });
        }
        if (name === 'Agent') {
          pendingSpawns.set(id, { name: str(input.subagent_type) ?? 'agent', brief: str(input.description) ?? str(input.prompt) ?? '' });
        }
      }
    }
  }
  return events;
}

function humanText(msg: Record<string, unknown> | null): string | null {
  if (!msg) return null;
  const c = msg.content;
  if (typeof c === 'string') return c;
  if (!Array.isArray(c)) return null;
  const parts: string[] = [];
  for (const block of c) {
    const b = obj(block);
    if (!b) continue;
    if (b.type === 'tool_result') return null;
    if (b.type === 'text' && typeof b.text === 'string') parts.push(b.text);
  }
  return parts.length ? parts.join('\n') : null;
}

function toolResultId(msg: Record<string, unknown> | null): string | null {
  if (!msg || !Array.isArray(msg.content)) return null;
  for (const block of msg.content) {
    const b = obj(block);
    if (b && b.type === 'tool_result' && typeof b.tool_use_id === 'string') return b.tool_use_id;
  }
  return null;
}

function editOps(name: string, input: Record<string, unknown>): { file: string; op: EditOp }[] {
  const file = str(input.file_path);
  if (!file) return [];
  if (name === 'Edit' && typeof input.old_string === 'string' && typeof input.new_string === 'string') {
    return [{ file, op: { type: 'replace', old: input.old_string, new: input.new_string, all: input.replace_all === true } }];
  }
  if (name === 'Write' && typeof input.content === 'string') {
    return [{ file, op: { type: 'write', content: input.content } }];
  }
  if (name === 'MultiEdit' && Array.isArray(input.edits)) {
    const out: { file: string; op: EditOp }[] = [];
    for (const e of input.edits) {
      const x = obj(e);
      if (x && typeof x.old_string === 'string' && typeof x.new_string === 'string') {
        out.push({ file, op: { type: 'replace', old: x.old_string, new: x.new_string, all: x.replace_all === true } });
      }
    }
    return out;
  }
  return [];
}

/** Tokens that look like file paths: contain a slash or end in a short extension. Best effort, used only for hints. */
export function pathTokens(command: string): string[] {
  const out = new Set<string>();
  for (const raw of command.split(/[\s'"`;|&()<>]+/)) {
    const t = raw.replace(/^[-=]+/, '');
    if (!t || t.startsWith('http')) continue;
    if (t.includes('/') || /\.[a-z0-9]{1,5}$/i.test(t)) {
      if (/^[\w./~-]+$/.test(t) && t !== '.' && t !== '..') out.add(t);
    }
  }
  return [...out];
}
```

```ts
import { existsSync, readdirSync, realpathSync, statSync } from 'node:fs';
import { join } from 'node:path';
import type { Adapter, Event, SessionRef } from '../types.js';
import { parseApplyPatch } from './apply-patch.js';
import { readJsonl, firstLine, obj, str, num } from './jsonl.js';
import { pathTokens } from './claude-code.js';

function real(p: string): string {
  try { return realpathSync(p); } catch { return p; }
}
function inside(root: string, cwd: string): boolean {
  const r = real(root), c = real(cwd);
  return c === r || c.startsWith(r.endsWith('/') ? r : r + '/');
}

function* walk(dir: string): Generator<string> {
  for (const e of readdirSync(dir, { withFileTypes: true })) {
    const p = join(dir, e.name);
    if (e.isDirectory()) yield* walk(p);
    else if (e.isFile() && e.name.startsWith('rollout-') && e.name.endsWith('.jsonl')) yield p;
  }
}

export const codex: Adapter = {
  harness: 'codex',

  async discover(repoRoot, home) {
    const root = join(home, '.codex', 'sessions');
    if (!existsSync(root)) return [];
    const refs: SessionRef[] = [];
    for (const path of walk(root)) {
      const head = obj(firstLine(path));
      const payload = head ? obj(head.payload) : null;
      if (!head || !payload || head.type !== 'session_meta') continue;
      const cwd = str(payload.cwd);
      if (!cwd || !inside(repoRoot, cwd)) continue;
      const startedAt = Date.parse(str(payload.timestamp) ?? str(head.timestamp) ?? '');
      if (Number.isNaN(startedAt)) continue;
      // Last timestamp requires reading the file; mtime is a cheap, accurate stand-in for a closed session.
      const endedAt = lastTimestamp(path) ?? statSync(path).mtimeMs;
      refs.push({ harness: 'codex', id: str(payload.id) ?? str(payload.session_id) ?? path, path, cwd, startedAt, endedAt });
    }
    return refs.sort((a, b) => a.startedAt - b.startedAt);
  },

  async read(ref) {
    const { rows, skipped } = readJsonl(ref.path);
    const events: Event[] = [];
    const sessionId = ref.id;
    let turnId = 'turn-0';
    let n = 0;

    for (const r of rows) {
      const o = obj(r); if (!o) continue;
      const at = Date.parse(str(o.timestamp) ?? '');
      if (Number.isNaN(at)) continue;
      const p = obj(o.payload); if (!p) continue;
      const type = str(o.type);
      const pt = str(p.type);
      const base = { sessionId, agentId: sessionId, turnId, at };

      if (type === 'turn_context') { turnId = str(p.turn_id) ?? `turn-${++n}`; continue; }

      if (type === 'event_msg') {
        if (pt === 'user_message' && str(p.message)) {
          events.push({ kind: 'prompt', id: `${turnId}:prompt:${++n}`, ...base, text: p.message as string });
        } else if (pt === 'agent_message' && str(p.message)) {
          events.push({ kind: 'reasoning', id: `${turnId}:msg:${++n}`, ...base, text: p.message as string, visible: true });
        } else if (pt === 'token_count') {
          const last = obj(obj(p.info)?.last_token_usage);
          if (last) {
            const cached = num(last.cached_input_tokens);
            events.push({
              kind: 'usage', id: `${turnId}:usage:${++n}`, ...base,
              input: Math.max(0, num(last.input_tokens) - cached), output: num(last.output_tokens),
              cacheRead: cached, cacheWrite: num(last.cache_write_input_tokens),
            });
          }
        } else if (pt === 'turn_aborted' && p.reason === 'interrupted') {
          const tid = str(p.turn_id) ?? turnId;
          events.push({ kind: 'interrupt', id: `${tid}:interrupt`, ...base, turnId: tid });
        }
        continue;
      }

      if (type !== 'response_item') continue;
      if (pt === 'reasoning' && Array.isArray(p.summary)) {
        const text = p.summary.map((s) => str(obj(s)?.text) ?? '').filter(Boolean).join('\n');
        if (text) events.push({ kind: 'reasoning', id: str(p.id) ?? `${turnId}:rs:${++n}`, ...base, text, visible: false });
      } else if (pt === 'function_call') {
        const callId = str(p.call_id) ?? str(p.id) ?? `${turnId}:fc:${++n}`;
        const command = shellCommand(str(p.name), str(p.arguments));
        if (command) events.push({ kind: 'shell', id: callId, ...base, command, touches: pathTokens(command) });
      } else if (pt === 'custom_tool_call' && p.name === 'apply_patch' && str(p.input)) {
        const callId = str(p.call_id) ?? str(p.id) ?? `${turnId}:patch:${++n}`;
        for (const { file, op } of parseApplyPatch(p.input as string)) {
          events.push({ kind: 'edit', id: callId, ...base, tool: 'apply_patch', file, op });
        }
      }
    }
    events.sort((a, b) => a.at - b.at);
    return { events, skipped };
  },
};

function lastTimestamp(path: string): number | null {
  let last: number | null = null;
  for (const r of readJsonl(path).rows) {
    const t = Date.parse(str(obj(r)?.timestamp) ?? '');
    if (!Number.isNaN(t)) last = t;
  }
  return last;
}

function shellCommand(name: string | null, args: string | null): string | null {
  if (!args || (name !== 'exec_command' && name !== 'shell' && name !== 'shell_command')) return null;
  let parsed: Record<string, unknown> | null;
  try { parsed = obj(JSON.parse(args)); } catch { return null; }
  if (!parsed) return null;
  const cmd = parsed.cmd ?? parsed.command;
  if (typeof cmd === 'string') return cmd;
  if (Array.isArray(cmd)) return cmd.filter((x): x is string => typeof x === 'string').join(' ');
  return null;
}
```

```ts
import type { Session, SessionRef, Window } from './types.js';

export async function findSessions(
  repoRoot: string,
  home: string,
  opts: { window: Window; ids?: string[] },
): Promise<{ selected: Session[]; all: SessionRef[] }> {
  const all: SessionRef[] = [];
  for (const a of adapters) all.push(...(await a.discover(repoRoot, home)));
  all.sort((a, b) => a.startedAt - b.startedAt);

  const wanted = opts.ids
    ? all.filter((r) => opts.ids!.some((id) => r.id.startsWith(id)))
    : all.filter((r) => r.startedAt <= opts.window.to && r.endedAt >= opts.window.from);

  const selected: Session[] = [];
  for (const ref of wanted) {
    const adapter = adapters.find((a) => a.harness === ref.harness)!;
    const { events, skipped } = await adapter.read(ref);
    selected.push({ ref, events, skipped });
  }
  return { selected, all };
}
```

```ts
import type { EditEvent, Harness, PromptEvent, ReasoningEvent, Session, ShellEvent, Usage, Window } from '../types.js';
import { ZERO_USAGE, addUsage } from '../types.js';

export interface Turn {
  id: string;
  sessionId: string;
  harness: Harness;
  prompt: PromptEvent | null;
  reasoning: ReasoningEvent[];
  usage: Usage | null;
  interrupted: boolean;
  prevInterrupted: boolean;
  firstAt: number;
}

export interface EventIndex {
  turns: Map<string, Turn>;
  editsByFile: Map<string, EditEvent[]>;
  shells: ShellEvent[];
  agents: Map<string, { name: string; brief: string }>;
  harnessOf: Map<string, Harness>;
}

export function relPath(repoRoot: string, abs: string): string | null {
  const root = repoRoot.replace(/[\\/]+$/, '');
  const a = abs.replace(/\\/g, '/');
  if (a === root) return null;
  if (!a.startsWith(root + '/')) return null;
  return a.slice(root.length + 1);
}

export function selectEdits(edits: EditEvent[], window: Window): EditEvent[] {
  return edits.filter((e) => e.at > window.from && e.at <= window.to);
}

export function indexEvents(sessions: Session[], repoRoot: string): EventIndex {
  const turns = new Map<string, Turn>();
  const editsByFile = new Map<string, EditEvent[]>();
  const shells: ShellEvent[] = [];
  const agents = new Map<string, { name: string; brief: string }>();
  const harnessOf = new Map<string, Harness>();

  for (const { ref, events } of sessions) {
    harnessOf.set(ref.id, ref.harness);
    const turn = (id: string, at: number): Turn => {
      let t = turns.get(id);
      if (!t) {
        t = { id, sessionId: ref.id, harness: ref.harness, prompt: null, reasoning: [], usage: null, interrupted: false, prevInterrupted: false, firstAt: at };
        turns.set(id, t);
      }
      if (at < t.firstAt) t.firstAt = at;
      return t;
    };
    for (const e of events) {
      const t = turn(e.turnId, e.at);
      switch (e.kind) {
        case 'prompt': t.prompt ??= e; break;
        case 'reasoning': t.reasoning.push(e); break;
        case 'usage': t.usage = addUsage(t.usage ?? ZERO_USAGE, e); break;
        case 'interrupt': t.interrupted = true; break;
        case 'spawn': agents.set(e.childAgentId, { name: e.name, brief: e.brief }); break;
        case 'shell': shells.push(e); break;
        case 'edit': {
          const rel = relPath(repoRoot, e.file);
          if (!rel) break;
          const list = editsByFile.get(rel) ?? [];
          list.push(e);
          editsByFile.set(rel, list);
        }
      }
    }
  }
  for (const list of editsByFile.values()) list.sort((a, b) => a.at - b.at);

  // prevInterrupted: walk each session's turns in time order.
  const bySession = new Map<string, Turn[]>();
  for (const t of turns.values()) {
    const l = bySession.get(t.sessionId) ?? [];
    l.push(t);
    bySession.set(t.sessionId, l);
  }
  for (const list of bySession.values()) {
    list.sort((a, b) => a.firstAt - b.firstAt);
    for (let i = 1; i < list.length; i++) list[i]!.prevInterrupted = list[i - 1]!.interrupted;
  }
  return { turns, editsByFile, shells, agents, harnessOf };
}
```

```ts
  has(path: string): boolean;          // repo-relative path exists in the working tree or index

  read(path: string): string | null;   // current content, for the import check
```

Rules (from spec section 5.4, with `unrequested` as repositioned):
- `untraced`: any line has `provenance === null`. Detail names a shell command from the window whose `touches` ends with the file path or its basename, if one exists: `shell in turn <id> mentioned this file: <first 60 chars>`; otherwise `no structured edit covers these lines`.
- `unrequested`: only when `turn.prompt` exists and `namedFiles(prompt)` is non-empty; raised when `file` is not in that list and no named file imports or is imported by `file`. Detail: `prompt named <a, b>`.
- `after-correction`: `turn.prompt` text's first 80 characters match `CORRECTION_WORDS`, or `turn.prevInterrupted`. Detail: `prompt begins "<first 60 chars>"` or `previous turn was interrupted`.
- `drifted`: `table.driftedAt !== null` and (`lead === null` or `lead.at > table.driftedAt`). Detail: `an earlier edit at <ISO time> did not match the file; attribution after it is best-effort`.
- `churned`: the hunk's added lines (trimmed, at least 8 chars) appear in the `old`, `new` or `content` text of edits from 3 or more distinct turns among `fileEdits`. Detail: `rewritten across <n> turns`.
- `subagent`: `lead` exists and `lead.agentId !== lead.sessionId`. Detail: `<agentName>: <brief>` when known, else `subagent <agentId>`.

```ts
import type { AnnotatedLine, EditEvent, Flag, FlagHit, LineTable, Provenance, ShellEvent } from '../types.js';
import type { Turn } from './index.js';

export interface RepoFiles {
  has(path: string): boolean;
  byBasename(name: string): string[];
  read(path: string): string | null;
}

export interface HunkFacts {
  file: string;
  lines: AnnotatedLine[];
  lead: Provenance | null;
  turn: Turn | null;
  table: LineTable;
  fileEdits: EditEvent[];
  shells: ShellEvent[];
  repo: RepoFiles;
}

export const FLAG_ORDER: Flag[] = ['untraced', 'unrequested', 'after-correction', 'drifted', 'churned', 'subagent'];

export const CORRECTION_WORDS = /\b(no|don't|do not|stop|revert|undo|wrong|instead|not what i)\b/i;
const CORRECTION_WINDOW = 80;
const CHURN_TURNS = 3;
const CHURN_MIN_CHARS = 8;

export function flagHunk(f: HunkFacts): FlagHit[] {
  const hits: FlagHit[] = [];
  const push = (flag: Flag, detail: string) => hits.push({ flag, detail });

  if (f.lines.some((l) => l.provenance === null)) {
    const sh = f.shells.find((s) => s.touches.some((t) => f.file === t || f.file.endsWith('/' + t) || t.endsWith('/' + f.file) || t === basename(f.file)));
    push('untraced', sh ? `shell in turn ${sh.turnId} mentioned this file: ${sh.command.slice(0, 60)}` : 'no structured edit covers these lines');
  }

  const promptText = f.turn?.prompt?.text ?? null;
  if (promptText !== null) {
    const named = namedFiles(promptText, f.repo);
    if (named.length && !named.includes(f.file) && !named.some((n) => related(n, f.file, f.repo))) {
      push('unrequested', `prompt named ${named.join(', ')}`);
    }
  }

  if (f.turn) {
    const head = (promptText ?? '').slice(0, CORRECTION_WINDOW);
    if (CORRECTION_WORDS.test(head)) push('after-correction', `prompt begins "${(promptText ?? '').slice(0, 60)}"`);
    else if (f.turn.prevInterrupted) push('after-correction', 'previous turn was interrupted');
  }

  if (f.table.driftedAt !== null && (f.lead === null || f.lead.at > f.table.driftedAt)) {
    push('drifted', `an earlier edit at ${new Date(f.table.driftedAt).toISOString()} did not match the file; attribution after it is best-effort`);
  }

  const needles = f.lines.map((l) => l.text.trim()).filter((t) => t.length >= CHURN_MIN_CHARS);
  if (needles.length) {
    const turns = new Set<string>();
    for (const e of f.fileEdits) {
      const hay = e.op.type === 'replace' ? e.op.old + '\n' + e.op.new : e.op.type === 'write' ? e.op.content : '';
      if (needles.some((n) => hay.includes(n))) turns.add(e.turnId);
    }
    if (turns.size >= CHURN_TURNS) push('churned', `rewritten across ${turns.size} turns`);
  }

  if (f.lead && f.lead.agentId !== f.lead.sessionId) {
    push('subagent', f.lead.agentName ?? `subagent ${f.lead.agentId}`);
  }

  return hits.sort((a, b) => FLAG_ORDER.indexOf(a.flag) - FLAG_ORDER.indexOf(b.flag));
}

/** Repo paths a prompt names, by exact relative path or by basename. */
export function namedFiles(prompt: string, repo: RepoFiles): string[] {
  const out = new Set<string>();
  for (const raw of prompt.split(/[\s,;:()'"`]+/)) {
    const t = raw.replace(/[.?!]+$/, '');
    if (!t || !(t.includes('/') || /\.[a-z0-9]{1,5}$/i.test(t))) continue;
    if (repo.has(t)) { out.add(t); continue; }
    for (const p of repo.byBasename(t)) out.add(p);
  }
  return [...out];
}

const IMPORT = /(?:from|import|require\()\s*['"]([^'"]+)['"]|^\s*(?:from\s+(\S+)\s+import|import\s+([\w.]+))/gm;

/** True when a imports b or b imports a, judged by the last path segment without extension. */
function related(a: string, b: string, repo: RepoFiles): boolean {
  return imports(a, b, repo) || imports(b, a, repo);
}

function imports(from: string, target: string, repo: RepoFiles): boolean {
  const src = repo.read(from);
  if (!src) return false;
  const want = stem(target);
  for (const m of src.matchAll(IMPORT)) {
    const spec = m[1] ?? m[2] ?? m[3] ?? '';
    if (stem(spec.replace(/\./g, '/')) === want || stem(spec) === want) return true;
  }
  return false;
}

function basename(p: string): string {
  return p.split('/').pop() ?? p;
}
function stem(p: string): string {
  return basename(p).replace(/\.[a-z0-9]+$/i, '');
}
```

```ts
export interface ResolveInput {
  repoRoot: string;
  range: string;                 // display string, e.g. "HEAD..working tree"
  window: Window;
  diffs: FileDiff[];
  sessions: Session[];
  baseText(path: string): string | null;   // file at the base rev

}

```

Line matching rule (spec 5.4 step 1, made precise): for added line `i` of a hunk, candidate index is `hunk.newStart - 1 + i` in the ledger. It matches when `strip(ledger.text) === strip(diff.text)` where `strip` removes one trailing `\r`. Otherwise, if exactly one ledger line has that stripped text, use it. Otherwise provenance is null.

Lead provenance: the `(turnId, editId)` pair that covers the most traced lines; ties go to the earliest `at`. `otherTurns` is the number of distinct other turn ids among traced lines.

```ts
import type { AnnotatedDiff, AnnotatedFile, AnnotatedHunk, AnnotatedLine, EditEvent, FileDiff, Flag, Hunk, LineTable, Provenance, Session, Usage, Window } from '../types.js';
import { ZERO_USAGE, addUsage } from '../types.js';
import { replay, tableText } from '../ledger/ledger.js';
import { indexEvents, selectEdits, type EventIndex, type Turn } from './index.js';
import { FLAG_ORDER, flagHunk, type RepoFiles } from './flags.js';

export interface ResolveInput {
  repoRoot: string;
  range: string;
  window: Window;
  diffs: FileDiff[];
  sessions: Session[];
  baseText(path: string): string | null;
  headText(path: string): string | null;
  repo: RepoFiles;
}

export function resolve(input: ResolveInput): AnnotatedDiff {
  const ix = indexEvents(input.sessions, input.repoRoot);
  const files = input.diffs.map((d) => resolveFile(d, ix, input));
  const flagged = Object.fromEntries(FLAG_ORDER.map((f) => [f, 0])) as Record<Flag, number>;
  let hunks = 0;
  let cost: Usage = ZERO_USAGE;
  const costedTurns = new Set<string>();
  for (const f of files) {
    for (const h of f.hunks) {
      hunks++;
      for (const hit of h.flags) flagged[hit.flag]++;
    }
    for (const t of f.turnIds) {
      if (costedTurns.has(t)) continue;
      costedTurns.add(t);
      const u = ix.turns.get(t)?.usage;
      if (u) cost = addUsage(cost, u);
    }
  }
  return {
    schemaVersion: 1,
    range: input.range,
    generatedAt: Date.now(),
    sessions: input.sessions.map((s) => s.ref),
    files,
    totals: { files: files.length, hunks, flagged, cost },
  };
}

function resolveFile(d: FileDiff, ix: EventIndex, input: ResolveInput): AnnotatedFile {
  const edits = selectEdits(ix.editsByFile.get(d.path) ?? [], input.window);
  const base = d.status === 'added' ? null : input.baseText(d.oldPath ?? d.path);
  const table = replay(base, edits);
  const actual = d.status === 'deleted' ? '' : input.headText(d.path) ?? '';
  const ledgerMismatch = strip(tableText(table)) !== strip(actual);

  const hunks = d.hunks.map((h) => resolveHunk(h, d.path, table, edits, ix, input.repo));
  const turnIds = [...new Set(hunks.flatMap((h) => h.lines.map((l) => l.provenance?.turnId)).filter((t): t is string => !!t))];
  let cost: Usage | null = null;
  for (const t of turnIds) {
    const u = ix.turns.get(t)?.usage;
    if (u) cost = addUsage(cost ?? ZERO_USAGE, u);
  }
  return { path: d.path, status: d.status, hunks, turnIds, cost, ledgerMismatch, driftedAt: table.driftedAt };
}

function resolveHunk(h: Hunk, file: string, table: LineTable, fileEdits: EditEvent[], ix: EventIndex, repo: RepoFiles): AnnotatedHunk {
  const byText = new Map<string, number[]>();
  table.lines.forEach((l, i) => {
    const k = strip(l.text);
    const arr = byText.get(k) ?? [];
    arr.push(i);
    byText.set(k, arr);
  });

  const lines: AnnotatedLine[] = h.added.map((text, i) => {
    const want = strip(text);
    const at = h.newStart - 1 + i;
    let idx: number | null = null;
    if (table.lines[at] && strip(table.lines[at]!.text) === want) idx = at;
    else {
      const cands = byText.get(want);
      if (cands && cands.length === 1) idx = cands[0]!;
    }
    const editId = idx === null ? null : table.lines[idx]!.editId;
    const edit = editId ? fileEdits.find((e) => e.id === editId) ?? null : null;
    return { text, provenance: edit ? provenance(edit, ix) : null };
  });

  const lead = pickLead(lines);
  const turnIds = new Set(lines.map((l) => l.provenance?.turnId).filter(Boolean));
  const otherTurns = Math.max(0, turnIds.size - (lead ? 1 : 0));
  const turn: Turn | null = lead ? ix.turns.get(lead.turnId) ?? null : null;
  const flags = flagHunk({ file, lines, lead, turn, table, fileEdits, shells: ix.shells, repo });

  return { oldStart: h.oldStart, oldLines: h.oldLines, newStart: h.newStart, newLines: h.newLines, removed: h.removed, lines, lead, otherTurns, flags };
}

function provenance(e: EditEvent, ix: EventIndex): Provenance {
  const turn = ix.turns.get(e.turnId);
  const reasoning = turn?.reasoning.filter((r) => r.visible && r.at <= e.at).at(-1) ?? turn?.reasoning.filter((r) => r.at <= e.at).at(-1) ?? null;
  const agentName = e.agentId === e.sessionId ? null : ix.agents.get(e.agentId)?.name ?? null;
  return {
    harness: ix.harnessOf.get(e.sessionId) ?? 'claude-code',
    sessionId: e.sessionId,
    turnId: e.turnId,
    agentId: e.agentId,
    agentName,
    prompt: turn?.prompt ? { text: turn.prompt.text, at: turn.prompt.at } : { text: '', at: turn?.firstAt ?? e.at },
    reasoning: reasoning ? { text: reasoning.text, at: reasoning.at } : null,
    tool: e.tool,
    editId: e.id,
    at: e.at,
    turnCost: turn?.usage ?? null,
  };
}

function pickLead(lines: AnnotatedLine[]): Provenance | null {
  const counts = new Map<string, { p: Provenance; n: number }>();
  for (const l of lines) {
    if (!l.provenance) continue;
    const k = `${l.provenance.turnId}\u0000${l.provenance.editId}`;
    const c = counts.get(k) ?? { p: l.provenance, n: 0 };
    c.n++;
    counts.set(k, c);
  }
  let best: { p: Provenance; n: number } | null = null;
  for (const c of counts.values()) {
    if (!best || c.n > best.n || (c.n === best.n && c.p.at < best.p.at)) best = c;
  }
  return best?.p ?? null;
}

function strip(s: string): string {
  return s.endsWith('\r') ? s.slice(0, -1) : s;
}
```

Note: `ledgerMismatch` compares whole-file text with `\r` stripped only at the end; a CRLF file whose edits were CRLF-exact still compares equal because both sides carry the same `\r`s.

```ts
import type { AnnotatedDiff, AnnotatedFile, AnnotatedHunk, Usage } from '../types.js';
import { FLAG_ORDER } from '../resolve/flags.js';
import { paint } from './ansi.js';

export function fmtTokens(u: Usage | null): string {
  if (!u) return '–';
  const n = u.input + u.output + u.cacheRead + u.cacheWrite;
  if (n >= 1_000_000) return `${(n / 1_000_000).toFixed(1)}M`;
  if (n >= 1000) return `${(n / 1000).toFixed(1)}k`;
  return String(n);
}

export function verdict(d: AnnotatedDiff): string {
  if (d.totals.hunks === 0) return 'no changes';
  const flaggedHunks = d.files.reduce((n, f) => n + f.hunks.filter((h) => h.flags.length > 0).length, 0);
  const head = `${d.totals.hunks} ${plural(d.totals.hunks, 'hunk')} across ${d.totals.files} ${plural(d.totals.files, 'file')}`;
  if (flaggedHunks === 0) return `${head}, nothing flagged`;
  const parts = FLAG_ORDER.filter((f) => d.totals.flagged[f] > 0).map((f) => `${d.totals.flagged[f]} ${f}`);
  return `${head}, ${flaggedHunks} need a look: ${parts.join(', ')}`;
}

export function renderTerminal(d: AnnotatedDiff, opts: { color: boolean; all: boolean }): string {
  const c = paint(opts.color);
  const out: string[] = [c.bold(verdict(d)), ''];

  const entries = d.files.flatMap((f) => f.hunks.map((h) => ({ f, h })));
  const flagged = entries.filter((e) => e.h.flags.length > 0).sort(byWorst);
  const rest = entries.filter((e) => e.h.flags.length === 0);

  for (const { f, h } of flagged) out.push(...hunkBlock(f, h, c), '');
  if (opts.all) {
    for (const { f, h } of rest) out.push(...hunkBlock(f, h, c), '');
  } else if (rest.length) {
    out.push(c.dim('unflagged:'));
    for (const f of d.files) {
      const n = f.hunks.filter((h) => h.flags.length === 0).length;
      if (n === 0) continue;
      out.push(c.dim(`  ${f.path}  ${n} ${plural(n, 'hunk')}  ${f.turnIds.length} ${plural(f.turnIds.length, 'turn')}  ${fmtTokens(f.cost)} tokens`));
    }
    out.push('');
  }
  return out.join('\n');
}

function hunkBlock(f: AnnotatedFile, h: AnnotatedHunk, c: ReturnType<typeof paint>): string[] {
  const lines: string[] = [`${c.bold(f.path)} ${c.cyan(range(h))}`];
  for (const fl of h.flags) lines.push(`  ${c.red('!')} ${c.yellow(fl.flag)}  ${fl.detail}`);
  if (h.lead) {
    const p = h.lead;
    const who = p.agentId === p.sessionId ? 'main agent' : `subagent ${p.agentName ?? p.agentId}`;
    lines.push(c.dim(`  turn ${p.turnId} · ${p.harness} · ${who} · ${fmtTokens(p.turnCost)} tokens · ${stamp(p.at)}`));
    lines.push(`  prompt: ${oneLine(p.prompt.text, 120)}`);
    if (p.reasoning) lines.push(c.dim(`  reasoning: ${oneLine(p.reasoning.text, 160)}`));
    if (h.otherTurns > 0) lines.push(c.dim(`  (+${h.otherTurns} other ${plural(h.otherTurns, 'turn')})`));
  } else {
    lines.push(c.dim('  (no provenance)'));
  }
  for (const r of h.removed) lines.push(c.red(`-${r}`));
  for (const l of h.lines) lines.push(c.green(`+${l.text}`));
  return lines;
}

function byWorst(a: { f: AnnotatedFile; h: AnnotatedHunk }, b: { f: AnnotatedFile; h: AnnotatedHunk }): number {
  const w = (h: AnnotatedHunk) => Math.min(...h.flags.map((x) => FLAG_ORDER.indexOf(x.flag)));
  return w(a.h) - w(b.h) || a.f.path.localeCompare(b.f.path) || a.h.newStart - b.h.newStart;
}

function range(h: AnnotatedHunk): string {
  const seg = (s: number, n: number) => (n === 1 ? `${s}` : `${s},${n}`);
  return `@@ -${seg(h.oldStart, h.oldLines)} +${seg(h.newStart, h.newLines)} @@`;
}

function stamp(ms: number): string {
  return new Date(ms).toISOString().slice(0, 16).replace('T', ' ');
}

function oneLine(s: string, max: number): string {
  const t = s.replace(/\s*\n\s*/g, ' ').trim();
  return t.length > max ? t.slice(0, max - 1) + '…' : t;
}

function plural(n: number, word: string): string {
  return n === 1 ? word : `${word}s`;
}

```

```ts
import type { AnnotatedDiff, AnnotatedFile, AnnotatedHunk } from '../types.js';
import { FLAG_ORDER } from '../resolve/flags.js';
import { fmtTokens, verdict } from './terminal.js';

export function renderHtml(d: AnnotatedDiff): string {
  const v = verdict(d);
  const entries = d.files.flatMap((f) => f.hunks.map((h) => ({ f, h })));
  const flagged = entries.filter((e) => e.h.flags.length > 0).sort((a, b) => worst(a.h) - worst(b.h) || a.f.path.localeCompare(b.f.path) || a.h.newStart - b.h.newStart);

  const counts = FLAG_ORDER.filter((f) => d.totals.flagged[f] > 0).map((f) => `<span class="chip ${f}">${d.totals.flagged[f]} ${f}</span>`).join(' ');
  const fileList = d.files.map((f) => {
    const n = f.hunks.filter((h) => h.flags.length).length;
    return `<li><a href="#f-${esc(f.path)}">${esc(f.path)}</a>${n ? ` <span class="count">${n}</span>` : ''}</li>`;
  }).join('\n');

  const flaggedHtml = flagged.map(({ f, h }) => hunk(f, h)).join('\n');
  const unflaggedHtml = d.files.map((f) => {
    const rest = f.hunks.filter((h) => h.flags.length === 0);
    if (!rest.length) return '';
    return `<details class="unflagged"><summary>${esc(f.path)} · ${rest.length} unflagged · ${f.turnIds.length} turn(s) · ${fmtTokens(f.cost)} tokens</summary>\n${rest.map((h) => hunk(f, h)).join('\n')}\n</details>`;
  }).join('\n');

  return `<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>whyline: ${esc(v)}</title>

</head>

function hunk(f: AnnotatedFile, h: AnnotatedHunk): string {
  const chips = h.flags.map((x) => `<span class="chip ${x.flag}" title="${esc(x.detail)}">${x.flag}</span> <span class="detail">${esc(x.detail)}</span>`).join('<br>');
  const p = h.lead;
  const who = p ? (p.agentId === p.sessionId ? 'main agent' : `subagent ${p.agentName ?? p.agentId}`) : '';
  const prov = p
    ? `<p class="prov">turn ${esc(p.turnId)} · ${p.harness} · ${esc(who)} · ${fmtTokens(p.turnCost)} tokens · ${new Date(p.at).toISOString().slice(0, 16).replace('T', ' ')}${h.otherTurns ? ` · +${h.otherTurns} other turn(s)` : ''}</p>
<details open><summary>prompt</summary><pre>${esc(p.prompt.text)}</pre></details>
${p.reasoning ? `<details><summary>reasoning</summary><pre>${esc(p.reasoning.text)}</pre></details>` : ''}`
    : '<p class="prov">no provenance</p>';
  const code = [...h.removed.map((r) => `<span class="del">-${esc(r)}</span>`), ...h.lines.map((l) => `<span class="add">+${esc(l.text)}</span>`)].join('\n');
  const seg = (s: number, n: number) => (n === 1 ? `${s}` : `${s},${n}`);
  return `<article class="hunk" id="f-${esc(f.path)}">
<h2>${esc(f.path)} <code>@@ -${seg(h.oldStart, h.oldLines)} +${seg(h.newStart, h.newLines)} @@</code></h2>
${chips ? `<p class="flags">${chips}</p>` : ''}
${prov}
<pre class="diff">${code}</pre>
</article>`;
}

function worst(h: AnnotatedHunk): number {
  return Math.min(...h.flags.map((x) => FLAG_ORDER.indexOf(x.flag)));
}

  return s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}
```

```ts
const USAGE = `whyline [range] [options]        annotate the diff (default: working tree vs HEAD)
whyline sessions                 list agent sessions found for this repo
whyline doctor                   show what whyline can and cannot see here

options
  --all            show unflagged hunks too

  --session <id>   use only this session (repeatable, prefix ok)
  --no-color       disable colors (NO_COLOR is also honored)

export async function run(argv: string[], io: Io): Promise<number> {
  let args: ReturnType<typeof parseOptions>;
  try {
    args = parseOptions(argv);
  } catch (e) {
    io.stderr.write(`${(e as Error).message}\n\n${USAGE}`);
    return 1;
  }
  if (args.values.help) { io.stdout.write(USAGE); return 0; }

  const root = repoRoot(io.cwd);
  if (!root) { io.stderr.write('whyline: not a git repository\n'); return 2; }

  const cmd = args.positionals[0];
  if (cmd === 'sessions') return sessions(root, io);
  if (cmd === 'doctor') return doctor(root, io);
  return review(root, cmd ?? null, args.values, io);
}

function parseOptions(argv: string[]) {
  return parseArgs({
    args: argv,
    allowPositionals: true,
    options: {
      all: { type: 'boolean', default: false },
      json: { type: 'boolean', default: false },
      html: { type: 'string' },
      since: { type: 'string' },
      session: { type: 'string', multiple: true },
      'no-color': { type: 'boolean', default: false },
      help: { type: 'boolean', short: 'h', default: false },
    },
  });
}

type Values = ReturnType<typeof parseOptions>['values'];

async function review(root: string, range: string | null, v: Values, io: Io): Promise<number> {
  const { base, head } = parseRange(range);
  let window: Window;
  try {
    window = { from: commitTime(root, base), to: head ? commitTime(root, head) : io.now() };
  } catch {
    io.stderr.write(`whyline: unknown revision in "${range}"\n`);
    return 1;
  }
  if (v.since) {
    const since = parseSince(v.since, io.now());
    if (since === null) { io.stderr.write(`whyline: cannot parse --since ${v.since}\n`); return 1; }
    window.from = since;
  }

  const diffs = parseUnifiedDiff(diffText(root, range));
  if (!head) {
    for (const p of untracked(root)) {
      const content = readWorkingFile(root, p);
      if (content !== null) diffs.push(syntheticAdded(p, content));
    }
  }
  if (diffs.length === 0) { io.stdout.write('no changes\n'); return 2; }

  const ids = v.session && v.session.length ? v.session : undefined;
  const { selected, all } = await findSessions(root, io.home, ids ? { window, ids } : { window });
  if (selected.length === 0) {
    io.stderr.write(noSessions(all, io.home, window));
    return 3;
  }

  const tracked = new Set([...lsFiles(root), ...untracked(root)]);
  const repo: RepoFiles = {
    has: (p) => tracked.has(p),
    byBasename: (n) => [...tracked].filter((p) => p.split('/').pop() === n),
    read: (p) => readWorkingFile(root, p),
  };
  const result = resolve({
    repoRoot: root,
    range: range ?? 'HEAD..working tree',
    window,
    diffs,
    sessions: selected,
    baseText: (p) => show(root, base, p),
    headText: (p) => (head ? show(root, head, p) : readWorkingFile(root, p)),
    repo,
  });

  if (v.json) { io.stdout.write(renderJson(result)); return 0; }
  if (v.html) {
    writeFileSync(v.html, renderHtml(result));
    io.stdout.write(`${verdict(result)}\nwrote ${v.html}\n`);
    return 0;
  }
  io.stdout.write(renderTerminal(result, { color: colorEnabled(v['no-color'], io.stdout, io.env), all: v.all }));
  return 0;
}

async function sessions(root: string, io: Io): Promise<number> {
  const { all } = await findSessions(root, io.home, { window: { from: 0, to: Number.MAX_SAFE_INTEGER }, ids: [''] });
  if (all.length === 0) { io.stderr.write(noSessions(all, io.home, null)); return 3; }
  io.stdout.write(all.map(line).join('\n') + '\n');
  return 0;
}

async function doctor(root: string, io: Io): Promise<number> {
  const out: string[] = [`repo: ${root}`];
  for (const dir of [join(io.home, '.claude', 'projects'), join(io.home, '.codex', 'sessions')]) {
    out.push(`${dir}: ${existsSync(dir) ? 'found' : 'missing'}`);
  }
  const { selected } = await findSessions(root, io.home, { window: { from: 0, to: Number.MAX_SAFE_INTEGER }, ids: [''] });
  for (const a of adapters) {
    const mine = selected.filter((s) => s.ref.harness === a.harness);
    const skipped = mine.reduce((n, s) => n + s.skipped, 0);
    const edits = mine.reduce((n, s) => n + s.events.filter((e) => e.kind === 'edit').length, 0);
    const shells = mine.reduce((n, s) => n + s.events.filter((e) => e.kind === 'shell').length, 0);
    out.push(`${a.harness}: ${mine.length} ${mine.length === 1 ? 'session' : 'sessions'}, ${edits} structured edits, ${shells} shell commands, ${skipped} unreadable lines`);
  }
  out.push('', 'known gap: edits made through shell commands (sed, heredocs, scripts) have no structured record and show as untraced.');
  io.stdout.write(out.join('\n') + '\n');
  return 0;
}

function line(r: SessionRef): string {
  const mins = Math.max(1, Math.round((r.endedAt - r.startedAt) / 60_000));
  return `${r.harness.padEnd(12)} ${r.id.slice(0, 12).padEnd(13)} ${new Date(r.startedAt).toISOString().slice(0, 16).replace('T', ' ')}  ${mins}m  ${r.cwd}`;
}

function noSessions(all: SessionRef[], home: string, window: Window | null): string {
  if (all.length === 0) {
    return `whyline: no agent sessions found for this repo\nlooked in ${join(home, '.claude/projects')} and ${join(home, '.codex/sessions')}\n`;
  }
  const span = window ? ` between ${new Date(window.from).toISOString()} and ${new Date(window.to).toISOString()}` : '';
  return `whyline: no matching sessions${span}; found these for this repo:\n${all.map(line).join('\n')}\nuse --since or --session to pick one\n`;
}

function parseSince(s: string, now: number): number | null {
  const m = /^(\d+)d$/.exec(s);
  if (m) return now - Number(m[1]) * 86_400_000;
  const t = Date.parse(s);
  return Number.isNaN(t) ? null : t;
}
```

Note on `sessions` and `doctor`: passing `ids: ['']` selects every session (every id starts with the empty string) without inventing a second code path in `findSessions`.

````markdown
# whyline

Review what an AI coding agent did before you commit it.

`whyline` reads the session transcripts that Claude Code and Codex already write to disk, matches every changed hunk in your diff back to the prompt and edit that produced it, and tells you which hunks to look at first.

```
$ npx whyline
3 hunks across 3 files, 2 need a look: 1 untraced, 1 unrequested

new.txt @@ -0,0 +1 @@
  ! untraced  no structured edit covers these lines
  (no provenance)
+by hand

src/z.ts @@ -1 +1 @@
  ! unrequested  prompt named src/a.ts
  turn p1 · claude-code · main agent · 72 tokens · 2026-10-10 21:14
  prompt: change two to 2 in src/a.ts
  reasoning: Doing it.
-z
+zz

unflagged:
  src/a.ts  1 hunk  1 turn  72 tokens
```

No install, no hooks, no account. It works on sessions you ran last week.

## What it flags

| flag | meaning |
|---|---|
| `untraced` | no structured edit in any session accounts for these lines. Hand edits, shell edits (`sed`, heredocs), or a session whyline could not find. |
| `unrequested` | your prompt named specific files and this is not one of them, nor imported by one. Only raised when the prompt named a file. |
| `after-correction` | written in a turn that started with "no", "don't", "revert", "wrong", "instead"… or right after you interrupted the agent. |
| `drifted` | an earlier edit in this file did not match when replayed, so attribution after it is best-effort. |
| `churned` | the same lines were rewritten across three or more turns. |
| `subagent` | written by a spawned agent whose reasoning you never saw directly. |

Every flag is a plain rule over the transcript and the diff. No model is called. When whyline cannot prove where a line came from, it says `untraced` instead of guessing.

## Usage

```
npx whyline                  # working tree vs HEAD, flagged hunks first
npx whyline --all            # every hunk
npx whyline main..HEAD       # any git range
npx whyline --html out.html  # self-contained report
npx whyline --json           # everything, for scripts
npx whyline sessions         # which sessions it found for this repo
npx whyline doctor           # what it can and cannot see on this machine
```

Sessions are matched to the repo by their working directory and to the diff by time. `--since 7d` and `--session <id>` override that.

## How it works

1. Adapters read `~/.claude/projects/**` and `~/.codex/sessions/**` into one event stream: prompts, reasoning, edits, shell commands, token usage, subagent spawns, interrupts.
2. A ledger replays the structured edits (Claude's `Edit`/`Write`, Codex's `apply_patch`) in order and remembers which edit last wrote each line.
3. The resolver runs `git diff --unified=0`, looks each added line up in the ledger, attaches the prompt, reasoning, agent and turn cost, and applies the flag rules.
4. Terminal, HTML and JSON renderers print the same result.

Edits made through shell commands have no structured record in either harness, so those lines come out `untraced`. That is a gap in the data, and whyline reports it rather than papering over it.

## Privacy

Transcripts are your private conversations. whyline makes no network calls of any kind, has zero runtime dependencies, and writes nothing except the file you name with `--html`. CI fails if any network module appears in `src/`.

## Related tools

- [Agit](https://github.com/agitHQ/agit) and [Entire](https://github.com/entireio/cli) answer "which prompt wrote this line" with `blame` and `why` commands, and go further on session sharing, forking and team capture. whyline builds the same provenance layer but puts the review question first: which hunks should I worry about?
- [Agent Blame](https://github.com/mesa-dot-dev/agentblame) marks lines as AI- or human-written via editor hooks.

## Requirements

Node 20 or newer, git, and at least one Claude Code or Codex session run inside the repo.
````
